# Halton-MaskGIT — small 384 / cfg=1.0   LazyMAR 选点复刻 (HALTON_LAZY_VSIM) refresh sweep
#
# Model    : ImageNet_384_small.pth (H-MaskGIT-S, 77.9M, 12 层 / 512 dim / 24^2+1=577 token)
# Sampler  : halton, step=32, cfg_w=1.0, fp32, seed=42, global_bsize=32, 50000 imgs
#            sm_temp=1.0 / sm_temp_min=1.0 / temp_warmup=1 / sched_pow=2 / top_k=-1
# Gate     : step 5..30 走 partial, 前 5 步与最后 1 步恒为全量
# Layers   : LAZY_START=3 .. LAZY_END=11  (large 版是 L3-23; "从 LazyMAR 的打分层 3
#            一路用到最后一层"这一语义在 12 层模型上就是 L3-11)
#
# 与 large-384 cfg=0.5 的 lazyvsim sweep (results/halton_large384_lazyvsim_sweep.txt)
# 的差异仅两项: 模型 (1024/24层 -> 512/12层) 与 cfg_w (0.5 -> 1.0)。
# 选点规则 / 执行机制 / sampler / step / seed / bsize / dtype / 温度 / sched 完全一致。
#
# ============================================================================
# 方案: 只换"选哪些 token 重算", 执行机制与 HALTON_LAZY_CACHE 共用
# ----------------------------------------------------------------------------
#   score_i = 1 - cos( V_l(t)_i , V_l(t-1)_i )     l = LAZY_START = 3  (fp32 打分)
#   active  = TopK_{k_t}(score),  k_t = ceil(rho_t * N)
#   rho_t   = LazyMAR 的 RETAIN_RATIO_SCHEDULE, 64 步表按生成进度重采样到 32 步
#   **没有任何强制 token**: U_t / U_{t-1} / register 全部只按 V 的变化量竞争名额。
#   CFG 两半 ([cond ; uncond]) 共享同一份分数。
#   执行: Q 只算 active; K/V 走 per-layer 全长缓存; FFN 只算 active; 出口层缓存
#         回填 inactive 行; head 也只算 active 行。
#
# 与 lazycache (r=1, results/halton_small384_lazycache_sweep.txt) 的对照:
#   lazycache : active = U_t ∪ U_{t-1} ∪ register, 纯调度决定, k/N ≈ 0.057 恒定,
#               lazy 区间 = 全部 12 层 (L0-11)
#   lazyvsim  : active = TopK(V 余弦变化量), 内容自适应, k/N = rho_t 随 step 衰减
#               (partial 步平均 k/N ≈ 0.31), lazy 区间 = L3-11 (层 0..2 每步全量,
#               给入口层打分攒材料)
#
# refresh 语义 (Sampler/halton_sampler.py:225-231): gated_step_counter 先判断后自增,
#       refresh 落在 counter = 0, N, 2N, ... —— 与 lazycache 逐步一致, 两方案在同一
#       个 N 下起效的 step 完全相同, 可直接对比。
#
# 接口: launch/eval_fid_small384_lazyvsim.sh
#   HALTON_LAZY_CACHE=1 HALTON_LAZY_VSIM=1 HALTON_LAZY_VSIM_SCHED=lazymar
#   HALTON_LAZY_START_LAYER=3 HALTON_LAZY_END_LAYER=11 HALTON_CACHE_REFRESH_N=<N>
#
# 复现: setsid nohup bash launch/run_lazyvsim_all_sweeps.sh &
#       (单档: REFRESH_N=3 bash launch/eval_fid_small384_lazyvsim.sh)
